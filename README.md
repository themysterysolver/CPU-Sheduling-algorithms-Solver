## CPU Sheduling solver

- This is a simple webpage devloped using `streamlit` and deployed with help of ***https://share.streamlit.io/***.
- This page solves
  - `FCFS` - First come first served
  - `SJF` - Shortest job first
  - `SRTF` - Shortest remainign time first
  - `PPS` - Premptive priority scheduling
  - `NPPS` - Non-premptive scheduling
  - `RR` - Round robin
